
# Análise de Feedbacks com IA

## Sobre a atividade
Desenvolvimento de um prompt para orientar a IA na análise de feedbacks de clientes bancários, identificando reclamações, elogios e oportunidades de melhoria.

## Entregável
Prompt estruturado com objetivo, contexto, dados disponíveis, critérios de análise e restrições.

## Resultado esperado
Obter uma análise clara, organizada e baseada exclusivamente nos dados fornecidos.
